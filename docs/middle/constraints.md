# Constraints: grove

App-wide; recorded any time, reviewed in phase 2. Always covered: budget, time, platform, GDPR (when there's personal data), licences.

First drafted by `/pre.constraints` on 2026-10-20 (question-pages/37) from p1. Reviewed in phase 2 on 2026-10-21 (question-pages/46): updated to the combined requirements (RQ-…) and app-wide needs (N-…); the owner is in Finland; C-12 (no outside requests) and C-13 (no payments) added. A €20 monthly budget agreed on page 46 was dropped on question-pages/47: the budget stays zero.

| ID | Kind | Constraint | Goes to (constitution: code / process rule; plan; requirement) | Needs affected |
|---|---|---|---|---|
| C-01 | Budget | **Zero**: nothing to run beyond the owner's Claude Pro: no paid AI API, no paid hosting or domain name (PR-p1-14, PR-p1-24; question-pages/37). Learners pay nothing; they use their own AI chat, free or paid. A €20-a-month plan (domain, rented server, grove's own AI) was agreed on question-pages/46 and dropped on question-pages/47. | constitution: process rule; plan input | N-15, N-18 |
| C-02 | Time | About 10 hours a day. **First version by Sunday 25 October 2026**, including the rest of the process (phase 2 and the Spec Kit build with tests). Its contents are the first build in `docs/middle/scope.md` (question-pages/47): the learning loop, accounts by invitation, terms and privacy basics, and demo content for reviewers. A second build follows right after Sunday (writing and grammar practice, packages, per-skill levels, Expand, easier texts, the reading test, long texts, game feel, pasted texts, retiring words, the shared bank and library). | constitution: process rule; plan input | N-10 |
| C-03 | Platform | A web app: desktop browser and phone-friendly web, a single column made for phones first (RQ-23); no native mobile app (PR-p1-19). Speech uses the browser's built-in voices, where the device has one for the language (RQ-20, X-p1-02). | plan input | N-19, N-03 |
| C-04 | GDPR | Grove holds personal data: account details (email, hashed password, RQ-157, RQ-218), each learner's learning history and progress, texts they paste, and later who shared each library text (RQ-135), reports and suspensions. Needed: terms of use and a privacy notice with a stated purpose for each kind of data (RQ-141, RQ-228); consent at sign-up; accounts for ages 13 and over only (X-p1-03; Finland's age of consent for online services is 13, Data Protection Act section 5); learners can have their data exported and deleted, by asking the owner for now (RQ-229); only what's necessary is collected. Accounts are held by Firebase Authentication (Google: email address and hashed password; question-pages/49), which the privacy notice names as a processor, along with the tunnel provider (Cloudflare), whose servers pass the traffic through, and says that what learners paste into their own AI is governed by that AI's terms. The owner and the data are in Finland (EU); the supervisory authority is the Data Protection Ombudsman. Forgotten passwords are reset by email through Firebase (RQ-219; question-pages/49). | constitution: code rules (consent at sign-up, age check, each with a test) and process rules (collect only what's needed; export and deletion handled on request); requirements | N-20, N-17, N-24, N-09, N-28 |
| C-05 | Licences | The shared bank (later) uses open data under share-alike licences: Wiktionary (CC BY-SA, plus GFDL) and the Swedish Kelly list (CC BY-SA 3.0, LGPL 3.0); Språkbanken's Flex frequency list is CC BY 4.0 (RQ-210, RQ-117). Every entry records its source and licence; a credits page names the sources; bank data built from share-alike sources may only be shared under the same licence. The primary licence pages are checked before import (F-p1-05). Code libraries and fonts must have licences that allow this use. | constitution: code rule (licence field per entry, credits page, both tested); plan input (check library and font licences) | N-08, N-27 |
| C-06 | Hosting | Grove runs on the owner's always-on computer in Finland, reached through a relay tunnel with no open ports at home (RQ-125, T-p1-09); it's unavailable when that computer is off (PR-p1-129). Backups every hour to another disk (Q-p1-02). The home internet contract must allow running a server (F-p1-98). No domain name (C-01): a free quick tunnel, whose address changes whenever the tunnel restarts and comes with no uptime promise; reviewers get the new link after a restart. | plan input; constitution: code rule (grove runs as its own limited user) | N-18, N-20 |
| C-07 | Copyright | Texts a learner pastes from elsewhere are usually under copyright: they stay private unless the learner confirms they may be shared (RQ-134); pasted articles only when not under copyright (RQ-166). AI-written texts are used under the AI providers' terms. | constitution: process rule; requirements | N-27, N-28 |
| C-08 | Outside AI | All AI work goes through the learner's own chat AI by copy-paste (RQ-182, RQ-183): one summary exchange per session plus optional part prompts (RQ-01, RQ-186). Free tiers cap messages and answer length, so answers must be usable with few fix-it rounds (RQ-185, Q-p1-04), and the learner can later choose the exchange size (RQ-348). Reviewers start with ready-made demo content, so they can try grove before using an AI (RQ-361, RQ-362). Automating the AI sites is out (PR-p1-134 dropped). | plan input | N-15, N-19 |
| C-09 | Language | Swedish only in the first build, explained in English (RQ-111; several languages cut for now, RQ-26). The design keeps room for other languages and scripts later (RQ-262, RQ-265). | plan input | N-30, N-40 |
| C-10 | Maintainer | One person builds, runs and checks grove (N-10): the first build stays small (R-p1-11), and upkeep must fit the time in C-02. | constitution: process rule | N-10 |
| C-11 | Context | Grove is a course project at first: the first version is open to the course's reviewers (at most 5) and the owner, by invitation (PR-p1-233). The GitHub repo is private, with reviewers invited as collaborators; its README holds grove's current link (RQ-364) and the reviewer invitation code (RQ-368) (question-pages/49). | plan input | N-18 |
| C-12 | Third parties | The page loads nothing from outside services when someone visits it: no Google Fonts, analytics or outside scripts. Fonts (Zen Kaku Gothic New, SIL Open Font Licence; RQ-331) are served by grove itself. Loading fonts from Google sends each visitor's IP address to Google, which is personal data under GDPR. Sign-in goes through grove's server, not the browser (RQ-367); the one exception is Firebase's password-reset page, reached from the reset email (question-pages/49). | constitution: code rule (no outside requests from the page, tested); plan input | N-20, N-24 |
| C-13 | Payments | No payments and no paid accounts (C-01; PR-p1-14). Paid accounts and real payments (question-pages/46) were dropped on question-pages/47. | plan input | N-15 |
