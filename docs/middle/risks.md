# Risks: grove (app-wide)

Phase 2 (`/pre.risks`, 2026-10-21; reviewed on question-pages/49). The prototypes' risks merged (sources named), plus risks that only appear in the combined app, against the current scope (first build by Sunday, second build right after: docs/middle/scope.md) and constraints (zero budget, the owner's computer behind a quick tunnel). Each risk is a testable failure scenario, ranked by cost of failure × likelihood.

Sources considered: the needs and requirements · the domain's typical risks (web: security, availability; content: correctness) · the four worlds · project risks (time, skills, budget) · the prototypes' records (technical problems and dead ends).
