## Full checks

### F-p1-01 (PR-p1-24, PR-p1-25, PR-p1-26, PR-p1-28, PR-p1-30, PR-p1-82)
- **Why checked:** depends on outside services (the learners' own AI chats); the whole main flow needs them.
- **Technical:** Works with any chat AI in principle (prompt in, one JSON block out); the prototype checks answers strictly. Real answers from Claude, ChatGPT and Gemini have never been tried, so how often they break the rules (JSON, at most 1 new word per sentence) is unknown.
- **Cost:** Free for the owner. Learners need some AI chat; free tiers exist but cap messages (Claude: a rolling window), so an hour's package in one prompt (PR-p1-82) or many fix-it rounds may hit the cap.
- **Time:** Fits: already built.
- **Skills** (can I verify it works?): Yes, by pasting real answers by hand.
- **Legal:** Learners use their AI under its own terms; grove only reads the pasted text.
- **Rating:** possible with limits
- **Reasoning:** The design avoids cost, but depends on free AI tiers whose limits change, and on AIs following strict rules.
- **Alternatives / reduced version:** No reduction proposed: parts of ~20 minutes are already the default (PR-p1-30). Try real answers early (round 4 topic suggestion 'Real AI answers').
- **Sources:** [Free tier message caps 2026 (Tech Insider)](https://tech-insider.org/?p=18958), [Free vs paid AI tools 2026 (Zemith)](https://zemith.com/en/contents/free-vs-paid-ai-tools-2026); numbers conflict between sources

### F-p1-02 (PR-p1-20)
- **Why checked:** hosting, a database and a background process, within 'nothing beyond Claude Pro' (PR-p1-24).
- **Technical:** A Node server plus Postgres is standard. Render's free web service sleeps after 15 minutes idle with a 30+ second cold start, so a background process can't run all the time; Fly.io has no free tier for new accounts.
- **Cost:** Free if: Render (750 h/month, 5 GB bandwidth) + Neon (0.5 GB, scales to zero, suspended if limits are hit) or Supabase (500 MB, paused after about a week idle). Render's own free Postgres expires after 30 days: not usable.
- **Time:** Fits.
- **Skills** (can I verify it works?): Yes for the app; free-tier limits need watching.
- **Legal:** Hosts' terms; personal data on a host in or outside the EU matters for GDPR (see F-p1-07).
- **Rating:** possible with limits; reduction X-p1-01
- **Reasoning:** Free tiers allow it, but with sleep, cold starts, small storage and pausing, and they change often.
- **Alternatives / reduced version:** X-p1-01: the background check (PR-p1-97) runs when the server is awake (after a paste, or when the owner opens the review list), not continuously.
- **Sources:** [Render, Neon, Supabase free tiers (flaviocopes, checked Sept 2026)](https://flaviocopes.com/hosting-free-tiers/), [State of free hosting 2026 (SnapDeploy, a competitor)](https://snapdeploy.dev/state-of-free-hosting), [Free PostgreSQL hosting (Swyftstack)](https://swyftstack.com/blog/free-postgresql-hosting)

### F-p1-03 (PR-p1-22, PR-p1-34, PR-p1-93)
- **Why checked:** depends on the device's built-in voices.
- **Technical:** Browser speech uses the device's voices. Whether a Swedish (sv-SE) voice exists varies: Chrome on Android may fall back to an English voice when the voice pack isn't installed; Chrome desktop voices need a connection; iOS uses Safari's voices.
- **Cost:** Free.
- **Time:** Fits.
- **Skills** (can I verify it works?): Partly: only on the devices I own.
- **Legal:** None.
- **Rating:** possible with limits; reduction X-p1-02
- **Reasoning:** Works where a voice is installed; grove can't install one.
- **Alternatives / reduced version:** X-p1-02: read aloud only where the device has a voice for the language, and say so (with how to install one) when it doesn't.
- **Sources:** [SpeechSynthesis in browsers and OSes (Readium)](https://readium.org/speech/docs/WebSpeech.html), [Read Aloud browser compatibility guide](https://read-aloud.com/guide-browser-compatibility.html)

### F-p1-04 (PR-p1-03, PR-p1-110)
- **Why checked:** each language needs its own content, voices, dictionary and word list.
- **Technical:** The code is language-neutral except seed content, the frequency list and dictionary import. Swedish has a frequency list with CEFR levels (Kelly); the Kelly project made lists for other languages too (to be checked per language).
- **Cost:** Free if open lists exist per language.
- **Time:** One language first fits; each extra language takes setup time.
- **Skills** (can I verify it works?): Only for languages I can read.
- **Legal:** Licences per language's sources.
- **Rating:** possible with limits
- **Reasoning:** Feasible language by language; quality depends on open resources for each.
- **Alternatives / reduced version:** No reduction now; Swedish first is already the case.
- **Sources:** [Swedish Kelly-list (Språkbanken)](https://spraakbanken.gu.se/en/resources/kelly), [Kelly-list description](https://svn.spraakbanken.gu.se/sb-arkiv/pub/resurstext/Kelly-list_eng.txt), [researchdata.se entry (CC-BY-SA 3.0, LGPL 3.0)](https://researchdata.se/en/catalogue/dataset/doi-10-23695-6act-rs25)

### F-p1-05 (PR-p1-89, PR-p1-94, PR-p1-103, PR-p1-113, PR-p1-119)
- **Why checked:** outside data sources with licences, and storage on a free database.
- **Technical:** Wiktionary dumps can be turned into a database (others have done it); the Swedish Kelly-list has 8,425 most common words, each with a CEFR level; Språkbanken's Flex frequency lexicon is CC BY 4.0.
- **Cost:** Free; storage must fit 0.5 GB (Neon) or 500 MB (Supabase), so only the Swedish part of Wiktionary, trimmed.
- **Time:** Import scripts: a few days.
- **Skills** (can I verify it works?): Yes, by spot-checking entries.
- **Legal:** Wiktionary text is CC BY-SA (sources disagree on 3.0 or 4.0) plus GFDL; Kelly is CC BY-SA 3.0 / LGPL 3.0. Both need credit, and shared data built from them must be offered under the same licence. Check the primary pages before import.
- **Rating:** possible with limits
- **Reasoning:** The data exists and is free, but licences bind how the shared bank can be shared, and storage is tight.
- **Alternatives / reduced version:** No reduction; add a licence and credit page (need N-p1-32).
- **Sources:** [Wikimedia CC BY-SA 4.0 FAQ](https://meta.wikimedia.org/wiki/Terms_of_use/Creative_Commons_4.0/FAQ), [Wiktionary-derived SQLite dataset (states CC BY-SA 4.0 + GFDL)](https://huggingface.co/datasets/suncat09/offline-dicts), [Wiktionary Dictionaries project](https://github.com/Vuizur/Wiktionary-Dictionaries); primary page to check: https://en.wiktionary.org/wiki/Wiktionary:Copyrights; [Swedish Kelly-list (Språkbanken)](https://spraakbanken.gu.se/en/resources/kelly), [Kelly-list description](https://svn.spraakbanken.gu.se/sb-arkiv/pub/resurstext/Kelly-list_eng.txt), [researchdata.se entry (CC-BY-SA 3.0, LGPL 3.0)](https://researchdata.se/en/catalogue/dataset/doi-10-23695-6act-rs25)

### F-p1-06 (PR-p1-97, PR-p1-104, PR-p1-111, PR-p1-112)
- **Why checked:** automatic checking of AI entries against a dictionary is uncertain.
- **Technical:** Word forms (inflections) compare well with a dictionary. Translations don't: synonyms and different wording make many correct entries 'disagree', so the owner's review list may fill quickly.
- **Cost:** Free.
- **Time:** Moderate.
- **Skills** (can I verify it works?): Yes, by measuring how many entries get flagged.
- **Legal:** None beyond F-p1-05.
- **Rating:** possible with limits; see X-p1-01
- **Reasoning:** Feasible, but the review list could become more than one owner can handle.
- **Alternatives / reduced version:** X-p1-01 (runs when awake). Also: only flag a translation when none of the dictionary's senses share a word with it (to decide in review).
- **Sources:** [Wikimedia CC BY-SA 4.0 FAQ](https://meta.wikimedia.org/wiki/Terms_of_use/Creative_Commons_4.0/FAQ), [Wiktionary-derived SQLite dataset (states CC BY-SA 4.0 + GFDL)](https://huggingface.co/datasets/suncat09/offline-dicts), [Wiktionary Dictionaries project](https://github.com/Vuizur/Wiktionary-Dictionaries); primary page to check: https://en.wiktionary.org/wiki/Wiktionary:Copyrights
